# DL Project: Predicting Earnings Announcement Day Direction

This project was developed as part of a Deep Learning course project. It focuses on predicting stock price reactions to earnings announcements by combining firm fundamentals, market data, and FinBERT-based news sentiment using deep learning models.

**Important note on data availability**  
Due to size constraints, some data files referenced in this repository are **not included on GitHub**. The complete dataset and intermediate files are available on the original **GitLab repository**: https://gitlab.ethz.ch/nsoldati/dl-project

---

## Overview
- **Task:** three-class classification (UP / DOWN / NEUTRAL stock price movement on the earnings-announcement day)
- **Dataset:** custom-built dataset of 1,222 U.S. equity earnings announcements (top-500 firms by market capitalization), combining 15 firm fundamentals, 3 price-based features (adjusted close, 3- and 6-day moving averages), and 3 FinBERT-based news sentiment scores over a 30-day pre-announcement window (feature dimension d = 21)
- **Label:** two-calendar-day announcement-window return with a ±3% threshold (UP / DOWN / NEUTRAL)
- **Models:** three naive baselines (always-NEUTRAL, always-UP, class-prior random), multinomial logistic regression, random forest, histogram gradient boosting, multilayer perceptron, LSTM, and Transformer — each evaluated with and without sentiment features
- **Evaluation:** strictly chronological train/validation/test split, five random seeds, bootstrap confidence intervals, and paired significance tests (exact McNemar, paired permutation) against naive baselines
- **Metrics:** accuracy, macro-F1, balanced accuracy, Matthews correlation coefficient (MCC), one-vs-rest ROC-AUC and PR-AUC, Brier score, and a custom cost metric that penalizes UP/DOWN reversals more heavily than neutral errors

---

## Key result

Under this protocol, **no model predicts announcement-day direction reliably**. No model improves on a trivial always-NEUTRAL strategy under the custom cost metric (best model cost 0.922 vs. 0.579 for permanent abstention), the deep architectures do not separate from the simpler benchmarks once results are averaged over seeds, and the incremental value of news sentiment is not statistically discernible. Paired significance tests, bootstrap confidence intervals, and threshold, modality, and temporal-embargo robustness checks all support this conclusion. The contribution of the project is a carefully controlled, reproducible assessment of the limited directional predictability available at the single-event, announcement-day horizon.

## Quickstart

1. **Create virtual environment** (optional)

2. **Install dependencies**  
   pip install -r requirements.txt

3. **Prepare data**  
   The dataset was generated offline using `dataset_generation/DL_project_data.ipynb` and saved as `DL_dataset.pkl`.  
   Due to size constraints, the raw and some of the processed data files are **not included in this GitHub repository**. They are available on the original GitLab repository:  
   https://gitlab.ethz.ch/nsoldati/dl-project

4. **Train and evaluate**  
   Run:  
   python src/models/train.py  

   The pipeline iterates over all models (baselines, logistic regression, random forest, gradient boosting, MLP, LSTM, Transformer), both with and without sentiment features, across five random seeds. Trained checkpoints are saved to `networks/` (one per model/feature-set/seed), and per-model predictions, metrics, and confusion matrices are written to `src/figures/`. On the ETH student cluster, submit the job with:  
   sbatch runner.sh

5. **Analysis and robustness**  
   After training, run `python src/models/analysis.py` for ROC-AUC, PR-AUC, Brier scores, bootstrap confidence intervals, and paired significance tests, and `python src/models/robustness.py` for the threshold, modality, and temporal-embargo checks.

### Chronological partitions
The usable sample comprises 1,222 earnings events, split strictly chronologically (feature standardization is fit on the training partition only):

| Partition  | Events | Firms | Date range               |
|------------|--------|-------|--------------------------|
| Train      | 706    | 499   | 2024-10-31 – 2025-02-28  |
| Validation | 364    | 363   | 2025-03-03 – 2025-05-02  |
| Test       | 152    | 152   | 2025-05-05 – 2025-06-20  |

Each (firm, announcement) event appears in a single partition; the same firm can recur across partitions in different quarters.

## Configuration
No centralized configuration system is used. Model architecture choices and preprocessing parameters are defined directly in the code, and key training options (model type, sentiment usage, seeds) are controlled via the `Config` class in `src/models/train.py`. The neural models use the Adam optimizer with a learning rate of 5×10⁻⁵, a batch size of 8, a dropout rate of 0.5, and 15 training epochs; the checkpoint with the lowest validation loss is retained for test evaluation. Each stochastic configuration is trained under five random seeds. Class imbalance is handled with weighted cross-entropy for the neural models and scikit-learn balanced weighting for the benchmarks.

## Usage
**Training and multi-seed evaluation:**  
Run `python src/models/train.py` to preprocess data (if needed), train the models across five seeds, and write per-model predictions and metrics to `src/figures/`.

**Statistical analysis and calibration:**  
Run `python src/models/analysis.py` to compute ROC-AUC, PR-AUC, Brier scores, bootstrap confidence intervals, and paired significance tests (exact McNemar, paired permutation).

**Robustness checks:**  
Run `python src/models/robustness.py` for the label-threshold, single-modality, and temporal-embargo analyses.

**Inference:**  
No standalone inference script is provided; predictions are generated as part of the training and evaluation pipeline.
